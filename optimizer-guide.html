1. Getting Started

The Optimizer is a powerful text processing tool designed to clean and standardize AI-generated content. All processing happens locally in your browser, ensuring complete privacy.

🔒 Privacy Guarantee: Your text never leaves your device. All processing is performed client-side with zero server communication.

What can it do? The Optimizer offers 6 powerful processing modes:

  • Language-specific character mapping (quotes, dashes, spaces)
  • Diacritic removal for international compatibility
  • Citation and reference cleaning
  • Markdown to plain text conversion
  • Fancy Unicode text normalization
  • Experimental em-dash sentence splitting

2. Language Mapping

Language mapping replaces region-specific characters with standardized alternatives according to the selected language profile.

🇨🇭 Swiss German

Optimized for Swiss writing standards:

ß → ss
« » → " "
— → -

🇩🇪 German

Standard German conventions:

„ " → " "
œ → oe, æ → ae
Various dash types → -

🇫🇷 French / 🇮🇹 Italian

Romance language support:

« » → " "

Standardized punctuation

🇺🇸 English (US/Int'l)

English quotation marks:

Normalized spaces/dashes

3. Basic Workflow

1

Example: "Text with diacrítics, **bold markdown**, [citations], and fancy 𝐔𝐧𝐢𝐜𝐨𝐝𝐞"
2

Choose your target language from the dropdown and enable the processing options you need (diacritics, citations, markdown, etc.).

4. Processing Options Explained

🗺️

Apply Language Character Mapping

Replaces special characters like quotes, dashes, and spaces according to the selected language mapping.

Before: „Zürich ist schön" — sagte er
After: "Zurich ist schoen" - sagte er
á→a

Remove Diacritics

Converts accented characters to their basic equivalents. Essential for Swiss German and international compatibility.

Examples: è→e, ä→ae, ö→oe, ü→ue, ñ→n, ç→c
📚

Remove Citation References

Removes source and citation references commonly found in AI outputs like Perplexity or ChatGPT.

Removes: [1], [2], (Source: XYZ), (https://...), superscripts¹²³
📝

Convert MD to Normal Text

Converts Markdown formatting to plain text by removing syntax commonly used in AI responses.

Removes: **bold**, *italic*, # headers, `code`, [links](url), etc.
𝐀→A

Remove Fancy Text Font

Converts fancy Unicode text styles back to plain characters.

Examples: 𝐛𝐨𝐥𝐝→bold, 𝑖𝑡𝑎𝑙𝑖𝑐→italic, 𝚖𝚘𝚗𝚘→mono
—→.

Replace em dash with new sentence

EXPERIMENTAL

Replaces em dashes (—) with periods and starts new sentences. Use with caution as results may vary.

Before: This is a sentence — and this continues
After: This is a sentence. And this continues

7. Privacy & Security

🔒 Privacy Guarantees

  • ✓ 100% Client-Side: All text processing happens entirely in your browser. No server communication.
  • ✓ No Data Transmission: Your text never leaves your device or gets sent to any server.
  • ✓ Local Storage Only: Only your settings preferences are saved (language, enabled options) - never your text content.
  • ✓ No Analytics: No tracking, no cookies for text data, complete privacy.

💡 Technical Note: The Optimizer loads language mapping files from local JSON files and processes everything using JavaScript in your browser's memory. It's completely offline-capable once the page loads.

8. Best Practices & Tips

🎯 For Best Results

  • • Start with fewer options enabled, add more as needed
  • • Test different language mappings to find the best fit
  • • Review the output before copying to ensure quality
  • • Use the experimental em-dash feature cautiously

⚡ For Efficiency

  • • Save your common settings by using the tool regularly
  • • Process large documents in batches if needed
  • • Use keyboard shortcuts (Ctrl+A, Ctrl+V, Ctrl+C)
  • • Clear input between different text types

🇨🇭 For Swiss German

  • • Always enable "Remove Diacritics" for proper ä→ae conversion
  • • Enable "Apply Language Mapping" for ß→ss and quotes
  • • This combination ensures proper Swiss German standardization
  • • Works great for official documents and communications

🤖 For AI Text

  • • Enable "Convert MD" to remove markdown formatting
  • • Enable "Remove Citations" for research-based outputs
  • • Check for fancy Unicode if copying from formatted sources
  • • Review automated changes before final use
