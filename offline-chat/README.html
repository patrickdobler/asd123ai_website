ASD123.ai Local Chat Offline Bundle

Open index.html in a Chromium-based browser with WebGPU support.

Click Load Model. The app first tries the bundled models folder. If the browser blocks direct file access, it will ask once for access to this offline-chat folder or the included models folder.

Expected model layout examples:

  • models/onnx-community--gemma-4-E2B-it-ONNX/config.json
  • models/onnx-community/gemma-4-E2B-it-ONNX/config.json

No executable or local server is required. For full offline use, this bundle needs vendor/transformers.iife.js, vendor/ort.webgpu.bundle.iife.js, and the selected model files under models.
