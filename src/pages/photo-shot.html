Photo-Shot

Create, edit and upscale images with several AI providers in one self-hosted app. Bring your own API keys; provider charges apply.

  • Self-hosted web app, usable on desktop and mobile.
  • Free, open-source software. Hosting and AI provider usage can cost money.
  • Requires Docker, provider API keys and server configuration. Follow the deployment guide.
Self-host Photo-ShotAll Apps

Create and refine images

Describe a new image or supply reference images, then edit a result again without starting over. Choose a provider and use the controls supported by its model.

Upscale and manage results

Increase image resolution, review generation costs and access image history from your devices. Results and history are stored on your server.

Copy photo metadata locally

Transfer selected EXIF information, such as location and capture time, between images. This separate metadata tool runs in your browser.

Where your data goes

AI generation sends prompts and reference images through your server to the provider you choose. API keys and image history stay on your server. Self-hosting the interface does not make AI generation local.

Set up your own instance

The deployment guide covers Docker, provider keys, access protection and networking. The supplied configuration expects a Traefik proxy network; adjust it for your own setup.
