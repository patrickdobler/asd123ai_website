RDP123

A lightweight, native remote desktop client for Mac. Manage Windows connections, share text and files, and launch SSH sessions from the menu bar.

Your Windows desktop in a Mac window

Open several remote computers in separate native windows. Switch between sessions through the Dock or Cmd+Tab, resize them, or work in full screen. When the last session closes, RDP123 returns to the menu bar.

Keep your connections in one place

Save and duplicate RDP profiles, or add SSH profiles that open in your preferred terminal. Each RDP connection has its own display, clipboard and audio settings. Automatic reconnect and Wake on LAN are available when you need them.

Sign in with a password or Microsoft Entra, including MFA. Entra requires a compatible Entra-joined Windows 11 computer and its hostname.

Copy, paste and dictate

Copy text, files and folders between Mac and Windows. Enable familiar Mac shortcuts such as Cmd+C and Cmd+V, or allow speech-to-text apps to paste dictated text into the active remote app.

Choose your SSH terminal, keyboard options and startup preferences in Global settings. Clipboard access can be restricted or disabled for each connection.

Install and connect

  • For Apple Silicon Macs running macOS 11 or newer.
  • Free and open source. Signed downloads, notarized by Apple.
  • Your Windows computer must accept Remote Desktop connections.
Download for macOS Guide & source code

Download the DMG and drag RDP123 into Applications. Or install with Homebrew:

brew install --cask asd123ch/tap/rdp123

Open RDP123, choose Settings from the menu bar, and add your first connection.

Your connections, your control

Passwords can be saved in macOS Keychain or entered for each connection. RDP123 asks you to trust a new server key before signing in and warns if it changes. No telemetry or account registration.

RDP connects to your configured computer; Entra sign-in contacts Microsoft. Optional daily update checks contact GitHub and can be turned off. Updates are downloaded and installed by you.

For everyday direct connections to Windows. Multi-monitor support and microphone forwarding are not available. See the guide for compatibility details.
