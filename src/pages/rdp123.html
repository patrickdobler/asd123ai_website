RDP123

Connect to Windows from your Mac. Manage remote sessions in native windows, with shared clipboard and secure password storage.

  • Native macOS app. macOS 11 or newer, Apple Silicon or Intel.
  • Free, open-source software. Build it on your Mac with Rust and Xcode Command Line Tools.
  • Connects to your remote computer. Passwords can be stored in macOS Keychain.
Build & install RDP123All Apps

Work with several remote computers

Each session has its own window and appears in the Dock and Cmd+Tab. Switch between computers as you would between other Mac windows.

Copy text, files and folders

Copy between Finder and Windows Explorer, share text through the clipboard, and play remote audio on your Mac. Clipboard access is configurable per connection.

Connect with your existing account

Use a password or Microsoft Entra authentication. Entra requires a compatible joined Windows 11 host and its hostname. Its sign-in opens the system WebKit view.

Start with one connection

Build and install the app, open Settings from the menu bar, and add your Windows computer. Review the server identity on first connection. The installation guide explains permissions and signing.
